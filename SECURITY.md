# Security

RIT is an early foundation, not a security boundary. Authentication, authorization, sandboxing, audit integrity, Git integration and protection from malicious code are not implemented. Do not rely on it to isolate agents or protect repositories.

No dedicated vulnerability reporting channel is configured in this repository. Until an owner publishes one, contact the repository owner privately through an appropriate available channel; do not post credentials or exploit details publicly. Avoid placing secrets in configuration or logs. No independent security audit has been performed.
