# Phase 10 — local protocol foundation

A bounded newline-delimited stdio JSON-RPC server implements MCP initialization negotiation (server version 2025-03-26), ping and an empty tools list; route middleware explicitly allows only these public discovery methods. Every other method, including tools/call, is denied before dispatch; no privileged tools, credential handling, HTTP listener or production operation exists. Rust protocol/transport integration tests exercise discovery and denied calls. Python and TypeScript have transport-injected request-client foundations; A Python SDK-to-stdio integration test passed; TypeScript typecheck is not yet established. This is a discovery prototype, not an MCP-complete implementation, security review, production API, or a substitute for central actor authorization. The middleware must be replaced/extended with the Phase 3 common authenticated policy before tools are added.
