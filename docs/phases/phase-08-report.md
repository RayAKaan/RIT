# Phase 8 — conflict evidence

`git_unmerged` extracts native Git unmerged entries from the existing read-only status model and marks each for human review. Semantic evidence and language-adapter contracts exist for TypeScript, Python and Go. No tree-sitter, Mergiraf, native merge execution, text-hunk analysis, semantic suggestions, confidence calibration or interactive resolution is implemented. No conflict is silently overwritten. No conflict-specific CLI is available yet.
