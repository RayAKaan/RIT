# API and protocol reference — actual state

No HTTP API, endpoint family, authenticated MCP tools, credentials, production authorization middleware or privileged service routes exist. The `rit-protocol` executable offers a local newline-delimited JSON-RPC discovery prototype. It handles legacy `initialize`, `ping`, and empty `tools/list`; it also implements the modern `server/discover` and version-metadata subset for 2026-07-28. All tool calls are denied. This is not a full MCP conformance implementation. Request size is capped at 65536 bytes and standard output contains protocol messages only. Caller-supplied JSON-RPC transport client foundations exist in Rust, Python and TypeScript; stdio discovery and denial have been tested, not authenticated product operations. No HTTP listener is started.
